# Baseline before the documentation core — 2026-08-24

This is the measured behavior of the architecture that the documentation core
replaced. It is the reference every later `rb-harness-benchmark/v1` report is
compared against.

## `cron2`, same prompt and same model

| Harness | Model | Duration | Cost | Result |
|---|---|---|---|---|
| DeepSeek Harness | `opencode-go/deepseek-v4-pro` | ~10 min | ~US$ 0.20 | useful documentation produced |
| RB Harness 0.3.14 | `opencode-go/deepseek-v4-pro` | >31 min (cancelled) | ~US$ 1.84 | no artifact published before cancellation |

Operator-reported figures for the same prompt and model in a comparable
environment. They are a product baseline, not a permanent provider price.

Preserved evidence from that trial:

- cancelled `cron2` run: `.rb-harness/runs/init-20260824145217-597e83d5fe-69ba72/`
  inside the `cron2` project;
- Memory trial state and logs: `.rb-harness/` inside the `rb-ia-memory` working copy;
- the semantic report that produced a new finding set after a full re-emission:
  `.rb-harness/verifications/20260824145848-fc891ccc-a534/report.json` in the same
  working copy — the evidence of non-convergence.

## What the baseline architecture did per run

| Property | Baseline (0.3.14) | Documentation core (0.4.0) |
|---|---|---|
| Provider roles | interview (unbounded rounds), generation, semantic audit, remediation | interview (≤2 rounds), generation, ≤1 structural repair |
| Interview ceiling | 128 adaptive rounds | 1 batch of ≤5 plus 1 follow-up of ≤3 |
| Provider filesystem access | writable project snapshot (`workspace-write`, `--auto`) | read-only; documents returned as a typed bundle |
| Workspace preparation | full project copy, up to 30 000 files / 768 MiB | artifact tree only |
| Prompt reference material | four reference documents plus workflow files (~30 KB) | code-owned contract digest plus workflow files (~10 KB) |
| Quality gate | second LLM auditing the first | deterministic contract validation |
| Convergence | audit → remediate → audit, unbounded | acyclic apart from two counted allowances |
| Cancellation | direct child plus a best-effort descendant sweep | process-group ownership with confirmed quiescence |
| Telemetry | observed bytes | stage durations, provider calls, tokens, cache |

## Reproducing the comparison

1. Run the DeepSeek Harness against the `cron2` prompt and record duration and
   cost from the provider's billing view.
2. Run `node scripts/benchmark.mjs` with the same prompt and model, passing the
   observed cost with `--observed-cost-usd`.
3. Compare the two reports. A deviation above the CA-001 limits must be
   explained with the stage durations and provider call counts in the report,
   not with a raised ceiling.
